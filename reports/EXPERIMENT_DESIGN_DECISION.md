# Experiment design decision

| Candidate design | Identifiability | Feasibility here | Decision |
| --- | --- | --- | --- |
| TeX proof-source graph | literal syntax only | high | retained as Level A |
| Family-held-out graph prediction | labels are lexical, not semantic | high | primary bounded experiment |
| Minimum-description-length producer models | depends on strong assumptions | medium | deferred |
| Controlled hidden-process model organisms | known ground truth and equivalence controls | high | retained |
| Lean counterfactual proofs | requires Lean plus semantic audit | unavailable | blocked |
| Open-weight causal interventions | needs competent inspectable model and compute | unavailable | blocked |

The selected program maximizes information gain about a key failure mode:
whether public artifacts can distinguish deliberately different hidden
processes. It does not select the easiest route to a mechanistic claim.
